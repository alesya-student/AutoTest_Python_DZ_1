Написаны следующие автотесты:
1. Автотест на калькулятор. Файл test_calculator_by_lesson10.py
2. Автотетст на форму регистрации. Файл test_registration_by_lesson10.py
Тест не стабильный. Часто нет соедениения с сервером.
3. Автотест на интернет магазин. Файл test_shop_by_lesson10.py

Подробное описание тестов, шаги, серьезность описаны непостредственно в тестах и методах.

Все тесты написаны с применением PageObject.
Все тесты проверены на соответствие стандартам PEP8.

Проверки произведены с помощью инструмента Allure
Тесты запускаются командой python -m pytest --alluredir allure-result
Информация о запущенных тестах сохраняются в папку allure-result

Для формирования визуального отчета используется команда allure serve allure-result
Передустановлена утилита Allure Report.
